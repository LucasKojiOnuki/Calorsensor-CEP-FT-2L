Fundamentos

O que é Temperatura?

Múltiplas definições, um único fenômeno físico fundamental que rege nosso cotidiano e a tecnologia dos sensores.

🎯

Definição Macroscópica

Grandeza física que indica o grau de agitação das moléculas. Determina a direção do fluxo de calor entre sistemas em contato.

⚛️

Definição Microscópica

Medida da energia cinética média das partículas. Quanto mais rápido as moléculas se movem, maior a temperatura do sistema.

🌡️

Escalas Termométricas

Celsius (°C), Fahrenheit (°F) e Kelvin (K). A escala absoluta começa no zero absoluto (-273,15°C), onde o movimento molecular cessa.

⚖️

Equilíbrio Térmico

Estado em que dois corpos em contato atingem a mesma temperatura, cessando a transferência líquida de calor entre eles.

🔥

Transferência de Calor

Ocorre por condução (contato), convecção (fluidos) e radiação (ondas eletromagnéticas). Base do funcionamento de qualquer sensor térmico.

📐

Capacidade Térmica

Quantidade de calor para variar 1°C. A água possui alta capacidade (1 cal/g°C), sendo ideal para piscinas aquecidas estáveis.

Tecnologias

Tipos de Sensores

Cada tecnologia possui vantagens específicas conforme a aplicação — da indústria à piscina olímpica.

ANALÓGICO

LM35

-55°C a +150°C

Sensor de precisão com saída linear de 10mV/°C. Fácil de usar com Arduino.

  • Saída proporcional em Celsius
  • Precisão de ±0,5°C
  • Baixo custo
DIGITAL 1-WIRE

DS18B20

-55°C a +125°C

Sensor digital à prova d'água, ideal para líquidos como a piscina do CEP.

  • Impermeável
  • Precisão de ±0,5°C
  • Resolução até 12 bits
TEMP + UMIDADE

DHT11 / DHT22

DHT22: -40 a 80°C

Medem temperatura e umidade relativa simultaneamente. Usados em estações meteorológicas.

  • Comunicação digital
  • DHT22 mais preciso
  • Ideal para ambientes
RESISTIVO

Termistor NTC/PTC

-55°C a +200°C

Resistor cuja resistência varia com a temperatura. Usados em termostatos.

  • Alta sensibilidade
  • Custo muito baixo
  • Requer calibração
INDUSTRIAL

PT100 / PT1000

-200°C a +850°C

RTD de platina. Altíssima precisão, usado em processos industriais e laboratoriais.

  • Precisão de ±0,1°C
  • Excelente estabilidade
  • Padrão industrial
SEM CONTATO

Infravermelho

-70°C a +380°C

Mede temperatura à distância através da radiação infravermelha emitida pelo objeto.

  • Medição sem contato
  • Resposta rápida
  • Termômetros clínicos

Códigos Práticos

Implementações reais em Arduino e Python para você começar agora mesmo.

🔌 LM35 com Arduino Uno

Leitura analógica simples — converte tensão em temperatura.

// Sensor LM35 - Leitura de temperatura
const int pinoLM35 = A0;

void setup() {
  Serial.begin(9600);
  Serial.println("LM35 inicializado!");
}

void loop() {
  int leitura = analogRead(pinoLM35);
  float tensao = leitura * 5.0 / 1024.0;
  float tempC = tensao * 100.0;  // 10mV/°C
  
  Serial.print("Temperatura: ");
  Serial.print(tempC);
  Serial.println(" °C");
  
  delay(1000);
}

💧 DS18B20 Impermeável (piscina CEP)

Sensor digital à prova d'água — perfeito para monitorar a piscina.

// DS18B20 - Sensor submersível
#include <OneWire.h>
#include <DallasTemperature.h>

const int pinoDados = 2;
OneWire oneWire(pinoDados);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  sensors.begin();
}

void loop() {
  sensors.requestTemperatures();
  float temp = sensors.getTempCByIndex(0);
  
  Serial.print("Temp. da água: ");
  Serial.print(temp);
  Serial.println(" °C");
  
  if(temp < 26.0) Serial.println("⚠ Aquecer piscina!");
  
  delay(2000);
}

🌬️ DHT22 — Temperatura e Umidade

Monitora ambiente ao redor da piscina (umidade do ar é crítica!).

// DHT22 - Ambiente da piscina
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT22

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  
  if(isnan(t) || isnan(h)) {
    Serial.println("Erro na leitura!");
    return;
  }
  
  Serial.print("Ar: ");
  Serial.print(t); Serial.print("°C | ");
  Serial.print(h); Serial.println("%");
  
  delay(2000);
}

🐍 Python no Raspberry Pi

Leitura via biblioteca Adafruit para monitoramento contínuo.

# Monitor de temperatura - Raspberry Pi
import time
import board
import adafruit_dht

sensor = adafruit_dht.DHT22(board.D4)
TEMP_MIN = 26.0   # Ideal para piscina
TEMP_MAX = 29.0

try:
    while True:
        try:
            temp = sensor.temperature
            umid = sensor.humidity
            if temp is not None:
                print(f"Temp: {temp:.1f}°C | Umidade: {umid:.1f}%")
                if temp < TEMP_MIN:
                    print("🔥 Ligar aquecedor!")
                elif temp > TEMP_MAX:
                    print("❄️ Resfriar água!")
        except RuntimeError as e:
            print(f"Erro: {e}")
        time.sleep(3)
except KeyboardInterrupt:
    print("Monitor encerrado.")
Estudo de caso

Piscina do Colégio Estadual do Paraná

Uma piscina olímpica com dimensões impressionantes e um desafio térmico único.

📍 CEP • CURITIBA

Piscina Olímpica com Altura Desproporcional

A piscina do Colégio Estadual do Paraná é uma verdadeira obra de engenharia: segue o padrão olímpico de 50 metros de comprimento, porém apresenta uma profundidade acima do convencional, criando uma proporção incomum entre largura/comprimento e altura.

Essa característica arquitetônica exige um sistema de aquecimento robusto, pois o volume de água é significativamente maior que o de uma piscina olímpica padrão, demandando mais energia térmica para atingir a temperatura ideal de competição (26°C a 28°C).

Sensores como o DS18B20 e PT100 são estrategicamente posicionados em diferentes profundidades para monitorar gradientes térmicos, garantindo conforto e segurança aos atletas.
